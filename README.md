## What it does

Writing status reports is about organization, not typing. The hard part is deciding which of the 20 things you did this week actually matter, quantifying wins without bragging, and surfacing problems without looking helpless.

This pack turns scattered work traces (chat logs, todos, calendar, git commits, notes) into a repeatable reporting pipeline: pick a template (daily / weekly / monthly), choose the audience (manager / cross-team / exec), and generate conclusion-first.

## What you get

- Structured reports: Core progress (max 3, each = result + number + impact), Key metrics (WoW delta), Issues & risks (issue + mitigation already taken + support needed), Next week (deliverable-oriented).
- Three template shapes: daily 3-part, weekly 5-part, monthly business view.
- Multi-audience versions in one pass (direct manager / cross-team / exec) with depth and tone tuned per reader.
- Export to Markdown / email body / Slack or Teams message.
