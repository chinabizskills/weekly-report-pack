# Weekly Report Pack

Auto-generate structured weekly/daily/monthly reports from scattered work traces (chats, todos, calendar, git commits, notes). Quantified wins, risks with actions, deliverable-oriented next steps. Multi-audience versions for manager / cross-team / exec.

## What's inside
- `SKILL.md` — drop-in skill for agent/Copilot-style workflows. Copy it into your agent's skills folder (or paste into your assistant's system prompt) to activate.

## Install
1. Copy `SKILL.md` into your agent's skills directory, **or**
2. Paste the contents of `SKILL.md` into your assistant's custom instructions.
